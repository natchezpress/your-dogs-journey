# Dedication backgrounds

Forty-seven generated backgrounds for the dedication maker, version 1.0, plus a manifest. Jetson's Spots (six real photos) are added separately.

- `*.webp` — full-resolution web copies (1648×2944 for the 9:16 masters, 2048×2048 for the Cream tile), WebP quality 86. These are what the app serves.
- `backgrounds.json` — one entry per background: group, date window, In Memory flag, defaults, and the busy-sky flag that turns on the text shadow.
- `sources.tsv` — the Midjourney job id and image index each file came from, so any master can be re-pulled from `https://cdn.midjourney.com/<job_id>/0_<index>.png`.

The 2K PNG masters live in Drive under STAGING › DedicationWall_Backgrounds › 02_Final_2K. Eight of the painted masters had a scribbled signature along the bottom edge that was painted out before export (Main Street, The Road East, Summer Close-Up, Valentine's Close-Up, Thanksgiving Close-Up, December Close-Up, Easter Bunny, Birthday Cupcake).

One 9:16 master per background; the app cuts the 4:5 feed and 1:1 card from it by trimming the top and bottom 15 percent.
